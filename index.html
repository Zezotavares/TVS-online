Sobre o WebTV Live

Este aplicativo foi desenvolvido em HTML5, Tailwind CSS e Vanilla JavaScript, sendo 100% otimizado para rodar diretamente no GitHub Pages.

Como hospedar no GitHub Pages:

  1. Crie um repositório público no GitHub.
  2. Salve este arquivo como index.html na raiz.
  3. Vá em Settings > Pages no seu repositório.
  4. Em Build and deployment, selecione a branch main (ou master) e clique em Save.

Seus canais personalizados são salvos automaticamente no navegador (localStorage), permitindo que você monte sua lista de favoritos e streams privados com total privacidade.
